# Chapter 5 result sets: index

Each exhibit of the book's Chapter 5, "Rail-Only Backend with VLANs", mapped to the result file and lines it quotes. Every set here comes from one recorded deployment of `ch05` under build A revision 2 on 2026-10-29, from wiped disks, at host tick 10000 on containerlab 0.82.0, every command run in tmux under `script` so that each journal shows the command exactly as typed (N/chain.log:1 to :33): `make down` and `make wipe` at 00:00:46, `make up` from 00:02:47 to 00:10:29, `make audit`, `make trace`, `make drills PASSES=3`, `make break-5a`, `make heal-5a`, `make rpf`, `make record` from 00:20:21 to 00:21:50, and `make down` to 00:21:58. No container restarted between the end of `make up` and the end of `make record` (N/startedat-after-up.txt, N/startedat-before-record.txt and N/startedat-after-record.txt list the same start times, every one `restarts=0`). Times are the lab host's clock, UTC. `../RESULTS.md` says what the deployment proved. Paths are relative to this directory.

The revision 1 sets this directory held (a deployment on 2026-10-21 and a second, for `make rpf` alone, on 2026-10-27, under the revision 1 node names, with every rail port at the factory MTU 9100 and no spanning tree, BPDU guard or storm control) are superseded and no longer in the repository; "Superseded sets" lists them.
